# Codex work notes

This directory stores durable, project-specific working notes produced during Codex sessions when the
decisions are useful to resume work but are not yet a finalized design document.

Rules:

- keep one topic per file;
- include the date and current state;
- record verified decisions, open questions, and exactly one nearest concrete next action;
- update the active topic in place; do not append duplicate daily summaries;
- never store passwords, private keys, wallets, tokens, production data, or licensed vendor binaries;
- promote stable architecture into the appropriate design or developer documentation when implementation
  begins.
